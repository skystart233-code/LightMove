# 轻移 LightMove · 使用说明

线性手感，稳、准、快。让每一次鼠标移动，都更可控。

轻移以减少手腕反复挪动为设计出发点，灵感来自轨迹球：保留普通鼠标熟悉的握持、指向与精细定位，借鉴小幅动作跨越屏幕的思路。通过可调节的速度曲线，让慢移与跨屏使用不同倍率；实际移动范围及舒适度需按个人设备与习惯体验。

轻移提供极简白色中文首页、现代窗口按钮、实时红点和可拖动曲线。使用指南可展开，常用调节集中在一页。当前为社区预览版，功能与兼容性持续完善。

基于 [RawAccelOfficial/rawaccel v1.7.1](https://github.com/RawAccelOfficial/rawaccel/releases/tag/v1.7.1) 的非官方界面汉化，维护于 `zh-CN` 分支。保留原项目 MIT 许可证和作者署名。

汉化范围：主窗口、菜单、八种曲线名称、参数标签、图表标题/图例、设备窗口、关于窗口、查找表校验提示、常见的未安装驱动提示。曲线保留英文名称便于对照官方文档。底层库返回的部分诊断文字、官方安装器及卸载器保留原文。

仅编译 C# 图形界面。驱动 `rawaccel.sys`、`wrapper.dll`、安装器、卸载器、`writer.exe` 和 `Newtonsoft.Json.dll` 均使用官方发布包原文件。配置字段、枚举值及鼠标加速算法保持上游格式；数字解析继续使用固定格式，避免中文区域设置影响小数点。

## 使用

1. 双击 `轻移LightMove.exe`。启动器会把必要文件解包到当前用户的 `%LocalAppData%\Programs\LightMove`，之后打开现代中文首页。
2. 驱动已安装并已重启的电脑可直接使用；新电脑会显示安装引导，按提示安装随附官方签名驱动并重启一次。软件不会自动重启。
3. 先移动鼠标观察红点，再拖动附近的蓝色圆点：向上拖更快，向下拖更稳。
4. 可从“精细办公 / 均衡顺手 / 快速跨屏”选择预览起点；满意后点“应用曲线”才会改变设置。
5. 首页按钮固定在底部；高缩放、小窗口时可滚动查看其余内容。首页已移除原版高级面板入口，常用调节集中在同一页面。

源码构建目录中的 `rawaccel.exe` 也默认打开现代首页；`--legacy` 打开中文原版高级界面。首页「启动设置」可开关登录 Windows 后自启，以及开机时收进托盘、关闭或最小化时收进托盘。开机自启默认关闭，只为当前用户设置，无需管理员权限；Windows 启动应用中的禁用状态优先。

默认关闭或最小化窗口会收进系统托盘，未应用的调整留在内存中。双击托盘图标或再次打开 EXE 可恢复已有窗口；右键托盘图标选择「退出轻移」可彻底退出。退出软件不会立即停用驱动当前曲线；若要恢复本次打开前的手感，应先点「恢复原曲线」。开机启动会加载上次保存的设置。

## 点一下，对比开启前后

实时手感卡片左侧的大开关可在「轻移已开启」与「原速对比中」之间切换，右侧可对照当前倍率与预览倍率。用同样的手部动作分别慢移和快速横扫，感受指针移动距离的区别。

- 原速对比暂停基础配置中的轻移效果，使用默认 1× 输出；不修改 Windows 鼠标选项、硬件 DPI 或设备配置。它不是恢复安装软件前的系统快照，单独分配到其他配置的设备仍保留其配置。
- 再点一次，精确恢复刚才已应用的完整配置；尚未应用的曲线、撤回与重做记录保留。
- 对比时灰线和实时红点显示当前的 1× 手感，蓝线仍可编辑。点击「应用曲线」会保存新曲线并重新开启轻移。
- 关闭窗口或退出程序不会自动恢复轻移。暂停状态及回到原曲线所需的备份会保留，重开后可再次开启。
- 切换期间暂时禁用重复操作，等待驱动回读确认。失败会显示原因，开关保持上次确认的状态。

## 拖点编辑曲线

曲线区域采用首版适中的图表比例，保留编辑所需高度。窗口高度不足时可纵向滚动，底部操作栏始终可见；不会随窗口变宽而扩成过大的正方形画布。

### 我的预设

点击预设行的「我的预设」，输入名称后点「保存当前」，将当前预览的控制点与 X/Y 联动状态保存到本机。最多保存 100 个；同名保存会自动编号，不覆盖旧方案。

选择已保存的方案并点「载入预览」，回到主界面后点击「应用曲线」才生效；载入操作可以用 Ctrl+Z 撤回。支持删除和撤回最近一次删除。文件原子保存，失败时保留原预设；重开或升级 EXE 后继续保留。预设只保存曲线与方向联动，不改变其他设备参数。

### 编辑操作

默认首页就是拖点编辑器。原版高级界面中仍可按 **Ctrl+E** 或从菜单进入编辑器。

- 拖动圆点改变曲线；双击空白处添加点，右键圆点或按 Delete 删除中间点。
- 默认开启网格吸附：标准档速度步长 1、倍率步长 0.1×；精细档为 0.5、0.05×。网格设置只影响编辑操作，不会改变已有控制点或生效曲线。
- 按住 Shift 拖动，接近其他控制点的高度时精确对齐，显示金色辅助线；即使关闭网格，Shift 也可临时启用吸附。按住 Alt 临时自由拖动，优先于 Shift。
- 选中点后可用方向键微调，Shift + 方向键按 5 倍步长调整，Alt + 方向键按 1/10 步长调整。
- 下方“选中点 · 速度”“倍率”可输入精确数值，不受网格舍入影响；首点速度固定为 0，首末点保留。
- 默认同步调整 X/Y，也可取消同步后分轴编辑，未编辑的轴保留原曲线。
- 灰色虚线与灰色菱形点位表示当前已生效的曲线，只读、用于对照；点位按当前真实曲线采样，只有成功应用后才随生效设置更新。蓝色实线与蓝色圆点是待应用曲线，可拖动编辑。
- 实心红点表示当前移动速度下的实际曲线位置，跟随真实鼠标移动，停下后回到左侧；空心橙点是应用后的预计位置。图下始终显示图例与说明：拖动只改预览，点击“应用曲线”后才生效。
- “撤回” / Ctrl+Z 回到上一个调整；“重做” / Ctrl+Y（也支持 Ctrl+Shift+Z）恢复刚撤回的一步。一次完整拖动算一步，增删点、数值修改、方向键、预设和方向联动也会记录。本次打开期间最多保留 100 步，撤回后继续编辑会清除旧重做分支。
- 已应用后仍可撤回之前的调整，但只生成预览，需要再次点击应用才改变手感；实时红点始终显示当前已生效曲线。
- “清空预览”一次清除所有尚未应用的修改，也可逐步撤回这次清空；“恢复原曲线”恢复本次打开编辑器之前的精确参数。
- 轴范围不会随拖动自动缩放。“更多设置”内的“显示完整曲线”可重新适配范围，“显示速度范围”只改变视图。
- 控制点会以平滑曲线生成官方驱动支持的灵敏度查找表（LUT）。预览绘制的是实际导出的折线插值，末端之后保持恒定倍率。
- 首次打开参数曲线时，编辑器取六个控制点生成可编辑近似曲线；灰虚线保留原参数曲线作对照。实际修改并应用后会转成 LUT，手感可能有差异。后续打开会恢复保存的控制点。

每次应用会先保存完整驱动配置到软件目录 `curve-backups`，再写入驱动并回读核对，成功后保存 `settings.json`。控制点缓存保存在 `.curve-editor.json`，更换参数曲线时会自动忽略不匹配的缓存。为兼容官方 v1.7.1 封装库的 X/Y 比较逻辑，导出的表最多使用 128 对坐标。

原图表默认关闭框选缩放，避免拖动时只剩一小段曲线。“图表 → 重置图表视图”可恢复完整视图；需要时可重新勾选“允许框选缩放”。

适用官方 v1.7.1 发布包支持的 Windows 10/11 x64。依赖 .NET Framework 4.7.2+ 和 Visual C++ 2019 x64 运行库，具体要求以[官方指南](https://github.com/RawAccelOfficial/rawaccel/blob/v1.7.1/doc/Guide.md)为准。

## “少挪鼠标，慢速精调”的调节方向

- 固定鼠标硬件 DPI，先用“灵敏度倍率”确定舒服的慢速操作手感。
- 可从“自然 Natural”曲线开始，温和提高快速移动时的灵敏度，并限制高速上限。
- “输入阈值”控制从什么手速开始加速；“上限”控制高速端的倍率。
- 使用自定义加速时，建议先关闭 Windows 的“提高指针精确度”，避免叠加加速。
- 曲线中的“线性 Linear”仍然是加速模式；关闭加速应选择“关闭 Off”。
- 右侧“当前值”显示已生效参数。修改输入框后，点击“应用”才写入驱动；“重置”按钮会重置驱动。

本包未代替你安装驱动、修改 DPI 或应用加速设置。由于尚未知晓鼠标 DPI 与屏幕配置，没有预先写入个人加速方案。

## 从源码编译中文界面

需要 Windows x64、Windows PowerShell 5.1 和 .NET SDK（包含 Roslyn 编译器）。优先使用本机 .NET Framework 4.7.2 引用程序集；缺少时使用系统 Framework 程序集。

先下载并解压官方 `RawAccel_v1.7.1.zip`。其官方 SHA-256：

```text
770fe3ae0919ca3c4d412f58c985eb27f5434decad809f7e8206de4e8852eec4
```

在仓库根目录执行，参数填解压后的 `RawAccel` 文件夹路径：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build-zh-CN.ps1 -OfficialDirectory C:\path\to\RawAccel
```

默认输出到 `artifacts\RawAccel-zh-CN`，包含官方依赖和英文原版备份。该脚本不会安装驱动或修改系统鼠标设置。中文界面属于本分支自行编译的非官方程序，不应冒充官方签名版本。
