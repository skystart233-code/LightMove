# 轻移 LightMove 验证记录

## 0.4.0-preview · 2026-10-21

- 对比开关、用户预设和最终画布比例已通过 1,556 项离线编辑器 / 桌面检查，以及七项输入接收器生命周期检查。公开构建结果以对应提交的 GitHub Actions 为准。
- 大开关按最新反馈放入实时手感卡片左侧，下方保留动态提示，右侧为当前 / 预览倍率；检查小窗口无横向滚动，生成开启 / 暂停 / 失败截图及八种交互状态预览。
- 统一逻辑尺寸下的 32 / 24 / 16 / 8 间距层级；原生高度不同的控件在同一行垂直居中。数值框使用等高圆角容器；底部关于入口与主要操作分开布局。默认大小和最小大小的离屏截图已检查，高画布保留纵向滚动及固定操作栏。
- 按用户最新反馈恢复首版适中的图表比例，预留约 260 逻辑像素的绘图区高度并允许随窗口纵向扩展，内容不足时滚动承载。预设检查覆盖重开读取、深拷贝、同名不覆盖、分轴、载入不写驱动、撤回 / 重做、删除恢复、损坏文件保留及保存失败回滚。
- 真实驱动往返测试通过：基础配置改为原速，精确回读核对，重新载入恢复记录，随后还原完整初始配置及保存的设置。Windows 鼠标选项保持不变。
- 已打包并在本机打开，新版连接驱动成功。打开前后完整驱动配置、Windows 鼠标选项及六项官方依赖哈希一致；已有配置先备份。
- 用户已确认开关的手感切换和恢复正常；随后按用户最新位置偏好将开关移入实时手感卡片。位置调整后的可见窗口效果仍待实际体验；离屏图不能代替桌面验收。

## 0.3.0-preview · 已发布版本

验证日期：2026-10-16。本记录对应 0.3.0-preview 的本机验证范围。

- 从官方 GitHub 固定 v1.7.1 下载依赖，驱动与相关依赖共六项的 SHA-256 与原保留包一致。
- 从独立的 LightMove 项目目录执行 `scripts/build.ps1`，构建、测试、打包及 SHA-256 文件生成成功。
- 1,477 项编辑器及桌面检查通过。覆盖曲线数学与导出、预览边界、分轴、撤回、灰色参考点、网格、界面尺寸与对比度、窗口绘制、启动偏好、运行项回滚、关闭 / 最小化收起、保留草稿和明确退出。
- 七项独立输入接收器生命周期检查通过。测试未向真实驱动写入新曲线；开机运行项测试使用替身，没有为测试开启真正的自启。
- 已安装包实测通过：明确退出后从其他工作目录以后台模式启动，初始窗口隐藏；程序读取自身目录配置；再次运行唤回同一进程窗口。
- 已安装包更新及后台启动测试前后的实际驱动配置一致。更新时 Windows 鼠标设置、官方依赖哈希保持一致；后台启动测试未改变用户开机启动项。
- 先前窗口残影与标题栏叠加问题，用户已确认修复后两处均正常，最小化恢复也正常。新启动页面检查了离屏渲染与布局；不能将其写成完整实机视觉验收。

尚未进行真实注销 / 重启后的登录启动验证，也未在干净系统或所有显示缩放、多显示器组合上完成兼容验证。Windows CI 配置已添加，远端执行结果以 GitHub Actions 对应提交的记录为准。
