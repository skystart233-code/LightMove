# 0.3.0-preview 本机验证

验证日期：2026-10-16。本记录对应 0.3.0-preview 的本机验证范围。

- 从官方 GitHub 固定 v1.7.1 下载依赖，驱动与相关依赖共六项的 SHA-256 与原保留包一致。
- 从独立的 LightMove 项目目录执行 `scripts/build.ps1`，构建、测试、打包及 SHA-256 文件生成成功。
- 1,477 项编辑器及桌面检查通过。覆盖曲线数学与导出、预览边界、分轴、撤回、灰色参考点、网格、界面尺寸与对比度、窗口绘制、启动偏好、运行项回滚、关闭 / 最小化收起、保留草稿和明确退出。
- 七项独立输入接收器生命周期检查通过。测试未向真实驱动写入新曲线；开机运行项测试使用替身，没有为测试开启真正的自启。
- 已安装包实测通过：明确退出后从其他工作目录以后台模式启动，初始窗口隐藏；程序读取自身目录配置；再次运行唤回同一进程窗口。
- 已安装包更新及后台启动测试前后的实际驱动配置一致。更新时 Windows 鼠标设置、官方依赖哈希保持一致；后台启动测试未改变用户开机启动项。
- 先前窗口残影与标题栏叠加问题，用户已确认修复后两处均正常，最小化恢复也正常。新启动页面检查了离屏渲染与布局；不能将其写成完整实机视觉验收。

尚未进行真实注销 / 重启后的登录启动验证，也未在干净系统或所有显示缩放、多显示器组合上完成兼容验证。Windows CI 配置已添加，远端执行结果以 GitHub Actions 对应提交的记录为准。
