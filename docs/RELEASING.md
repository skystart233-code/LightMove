# 发布流程

公开同步前先审阅 README、功能与许可归属。当前变更须经维护者确认后才推送或创建 GitHub Release。

1. 在 Windows 执行完整构建与离线检查。
2. 实机验证红点、灰色参考点、应用 / 撤回、窗口缩放、托盘恢复及退出；验证开机启动时区分进程模拟与真正登录测试。
3. 检查源码不含个人配置、实际输入记录、私密路径或账户数据。保留 MIT 许可证与上游来源。
4. 更新 `project.json`、启动器程序集版本与 `CHANGELOG.md`；原始驱动兼容版本不要随桌面版本修改。
5. 生成单文件 EXE、SHA-256 与源代码快照。记录官方依赖哈希。
6. 审核通过后提交、推送，再发布带版本号的 Release，附 EXE、SHA-256、变更说明及验证限制。

Windows 界面包目前无额外代码签名；随附 Raw Accel 驱动保持官方签名。首次驱动安装在干净系统上的完整验证、其他 DPI / 多屏和真实登录启动需持续补充。不能据本机通过宣称已完成所有设备兼容验证。
