# 架构与状态

`Program` 创建上游设备 / 驱动后端，再创建现代编辑器，由 `TraySession` 管理窗口和进程生命周期。输入接收使用独立消息窗口，收起编辑器不会销毁它。

`CurveEditorForm` 管理两轴草稿、撤回历史与应用回调。蓝线来自待应用曲线；灰线和灰菱形来自已生效配置采样。`SettingsManager` 在应用时备份完整配置、写入驱动、严格回读并保存；成功后才更新灰色参考点。

`DesktopSettingsService` 将启动与托盘偏好保存在 `%LocalAppData%\LightMove\preferences.json`。开机启动使用当前用户 `Software\Microsoft\Windows\CurrentVersion\Run` 的 `LightMove` 项；路径带引号并附加 `--background`。只在用户开启后注册；更新启动目标不会自行开启自启，亦不绕过 Windows 的启动应用禁用状态。保存偏好失败时恢复原运行项。

单文件启动器解包到 `%LocalAppData%\Programs\LightMove\preview-<内容哈希>`。新版本会继承设置和曲线缓存；自启已开启时，新主程序将运行项更新至当前解包路径。入口显式设置工作目录，确保 Windows 登录启动时仍读取自己的配置。

默认关闭 / 最小化隐藏窗口，草稿保持在同一进程内；显式退出才释放托盘与后端资源。正在应用曲线时不允许退出。关闭、退出进程均不会自行关闭内核驱动的已生效曲线。

## 摇晃查找指针

`TraySession` 持有 `CursorLocator`，因此窗口隐藏后仍可工作，退出时一并释放。偏好 `ShakeToFindCursor` 默认开启，由 `DesktopSettingsService.Changed` 即时更新；关掉该功能即停止定时器并清除浮层。它与手感对比开关相互独立。

摇晃识别和原生指针尺寸处理适配自 MIT 项目 `0cch/ShakeToFindCursor`，来源版本和许可保存在 `third-party/ShakeToFindCursor/`，完整许可随单文件 EXE 打包。`ShakeDetector` 只保留最多 40 个、500 ms 内的移动增量，过滤抖动、长时间停顿和大幅坐标跳变；同一方向轴在短时间多次反转且速度足够才触发。按住任意鼠标键时清空识别与动画，不拦截或注入输入，不保存鼠标坐标记录。

`NativeCursorEffect` 临时替换标准系统指针，屏幕上仅保留原生指针，不使用浮层。每次效果开始前分别复制原指针；Windows 自带 Aero 箭头采用几何路径和 4 倍采样，默认文字光标采用抗锯齿几何图形，自定义主题优先读取 .cur / .ani 高清资源，再按动画尺寸生成原生 HCURSOR。停止后 100 ms 开始收缩，120 ms 内完成恢复；只有新的方向反转会延长效果，旧历史不续时。

首页在实时手感卡片下方提供独立的指针开关与说明，使用统一边距和独立设置行；不压缩既有曲线绘图区的最低高度。`TraySession` 将首页开关、偏好与托盘菜单绑定到同一偏好服务。`SetShakeToFindCursor` 仅原子保存偏好并通知订阅者，不修改开机启动注册表，也不触碰曲线预览、撤回历史或驱动。首页只在保存成功后显示新状态，失败保留旧状态并显示说明；关闭开关会立即恢复当前指针。

`LightMove.CursorGuard.exe` 与主界面使用同一编译内容，通过独立入口运行，不启动驱动后端、窗口或网络。父进程和恢复助手各自持有原指针副本，使用本机会话内的随机命名事件协调准备、心跳与恢复。只有助手确认备份完成后才修改原生指针；主进程退出或 600 ms 无心跳时助手恢复。正常结束效果后解除恢复任务，退出软件时结束助手。不写指针主题注册表、不注入输入。应用自有指针、独占全屏和安全桌面不保证放大效果。
